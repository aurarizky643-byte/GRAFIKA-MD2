=== Lab 2: triangle gap bug ===
$ node triangle_gap_bug.mjs
== evidence: two triangles tiling a 6x6 quad along y = x ==
naive >=0 (no rule)        once=30  twice=6  gaps=0
strict >0 (no rule)        once=30  twice=0  gaps=6
top-left rule              once=36  twice=0  gaps=0

root cause : pixels whose centre lies exactly on the shared edge
             have an edge function == 0 in BOTH triangles.
the fix    : per-edge top-left bias -- 0 for a top/left edge,
             -1 otherwise -- so each on-edge pixel is claimed once.
proof      : top-left rule -> twice=0, gaps=0
wrote out/gap_coverage_buggy.ppm (red = double), out/gap_fixed.ppm
